# Three-Phase Inverter and Hysteresis Control of Grid-Connected Single-Phase Inverter 

This repository contains a MATLAB/Simulink-based power electronics simulation project on:

1. Three-Phase Inverter
2. Hysteresis Control of Grid-Connected Single-Phase Inverter


## Objectives

The main objectives of this experiment are:

-To develop and study a three-phase inverter using Simulink.
-To manage voltage rise and reduce the chance of appliance failure due to high voltage.
-To understand why voltage rise in a single-phase connection is higher compared to a three-phase power system.
-To construct and analyze a hysteresis control system for a grid-connected single-phase inverter using Simulink.
-To observe and analyze inverter output voltage, current, reference signal, and gate pulses.

## MATLAB Functions Code

### *Three-Phase Inverter Gate Signal Generation*

function [g1, g2, g3, g4, g5, g6] = fcn(Va, Vb, Vc, Vca)

if Va >= Vca
    g1 = 1;
    g2 = 0;
else
    g1 = 0;
    g2 = 1;
end

if Vb >= Vca
    g3 = 1;
    g4 = 0;
else
    g3 = 0;
    g4 = 1;
end

if Vc >= Vca
    g5 = 1;
    g6 = 0;
else
    g5 = 0;
    g6 = 1;
end

end

### *Hysteresis Controller MATLAB Function*

function [s, Ia, Ib] = fcn(I, Iref)

persistent d

if isempty(d)
    d = 1;
end

e = 1;

Ia = I + e;
Ib = I - e;

if Iref > Ia
    d = 0;
elseif Iref < Ib
    d = 1;
else
    d = d;
end

s = d;

end

## Working Principle

### Three-Phase Inverter

The three-phase inverter uses switching devices to produce AC output from a DC source. The switching signals are generated by comparing three-phase reference signals with a carrier signal. Based on the comparison, gate pulses are produced for the inverter switches.

The output voltage waveforms show the switching behavior of the inverter and the generated three-phase AC output.

### Hysteresis Control

In hysteresis control, the actual current is compared with the reference current. A hysteresis band is created using upper and lower limits.

- If the reference current is greater than the upper band, the switching state changes.
- If the reference current is lower than the lower band, the switching state changes again.
- If the current stays within the band, the previous switching state is maintained.

This method provides fast dynamic response and simple implementation for inverter current control.
